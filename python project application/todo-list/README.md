# To-Do List

A simple command-line To-Do List application built with Python.

## Goal

The goal of this project is to practice:

- Python functions
- Lists and dictionaries
- File handling
- CSV files
- Searching and updating data
- Git and GitHub

## Features

Planned features:

- Add a task
- Display all tasks
- Mark a task as completed
- Remove a task
- Search for a task
- Filter tasks
- Analyse task data
